# device/firmware — liuqin board firmware closure

[简体中文](README.md)

The 197 binary files under `usr/lib/firmware/` are the complete, pinned
firmware set the system needs: SM8475 DSP images (adsp/cdsp/slpi), QCA6490
WLAN (ath11k WCN6855, incl. the project-generated `board-2.bin`), QCA6490
Bluetooth (hpnv20/hpnv20g/hpnv21, hpbtfw), Novatek NT36532 touch firmware
(both panel variants), Adreno 730 GPU, CS35L41/CS35L63 audio DSP, the audio
topology (`qcom/sm8450/Xiaomi-Pad-6-Pro-tplg.bin`), the VPU blob and the
wireless regulatory database.

## Provenance

- Extracted offline from the retail fastboot ROM
  `OS2.0.6.0.VMYCNXM` (liuqin_images_15.0_cn) with
  `tools/build-liuqin-firmware-prep.sh`; per-file sha256 is pinned in
  `firmware.manifest` (sha256
  `012c413e0a5d5c3c14631fbdfe50da5c51e95ffc1ae431b8d93f776538b65ba2`).
- `ath11k/WCN6855/*/board-2.bin*` is generated by the project from the
  vendor tuple (`tools/build-liuqin-wifi5g-hsp2-tuple.sh`).
- The files are device-generic (identical for every Xiaomi Pad 6 Pro).
  Per-device data — speaker-protection calibration, sensor registry, WLAN
  MAC, Bluetooth address — is NEVER stored here; it is read from each
  unit's factory persist partition at install time
  (`tools/provision-liuqin-from-persist.sh`).

## Version policy

The pinned set is the validated OS2.0.6.0 baseline. Newer stock-ROM
revisions of these blobs are only adopted after on-device validation;
users on newer ROMs can safely run this set (see the version-sensitivity
analysis in the installation docs). The single authoritative copy lives
here; release assets are produced from this tree, never the reverse.
