# Linux 7.3 默认内核与验收

[构建指南](BUILD.md) ｜ [内核更新与恢复](KERNEL-UPDATES.md) ｜ [待改进与验证](DEVELOPMENT-STATUS.md)

默认安装到平板的系统内核为 **Linux 7.3 + Liuqin 设备适配**，固定来源见
[source.json](../build/kernel/source.json)。`installer.img` 自身在 RAM 中临时运行
[source-6.17.json](../build/kernel/source-6.17.json) 锁定的 Linux 6.17，负责安装操作；
它可以安装 7.3 系统，安装完成后平板运行 `boot.img` 中的 7.3 内核及 rootfs 中的配套模块。
默认版本切换不代表所有硬件批次和已有问题都已完成验收。

## 来源与保留范围

主线基线为 Torvalds `v7.3`（`c03c1a14507dfaf8b856c2608f9ac216021fc222`）。
迁移保留现有板级功能，公开补丁重放后的源码树与真机测试版本一致；
构建提交号可因源码装配方式不同而变化。

| 范围 | 保留内容 |
| --- | --- |
| 显示 | 面板选型、原厂命令、供电复位、PHY 时序、首帧背光、亮度曲线、调光、CABC、异常恢复；时钟门控继续关闭 |
| 输入与指纹 | 触屏/笔、磁吸键盘、Caps Lock 指示灯和平板模式、FPC 实际中断电平及 QSEECOM |
| 音频与相机 | CS35L41、AudioReach、麦克风路由、后摄 S5KJN1 和软件 ISP；不扩展前摄功能 |
| 通信与供电 | Wi-Fi、蓝牙、USB、传感器、MiPPS、电池单位修正 |
| 引导与系统 | ABL 格式、存储保护、ext4/Btrfs、Zstd、开关机画面方向、SELinux、Binder/Waydroid、zram、GPU 统计与恢复 |

当前使用 7.3 默认的**虚拟显示平面**，没有固定硬件平面的启动覆盖参数。
旧版 DSI 频率修正和 SMMU 接管已有对应主线实现，不重复叠加；
剩余时钟保护和 PLL 精度修正按新版接口保留。
7.3 上游将通用 QCE 加速驱动标为 `BROKEN`，没有强行开启，CPU 加密实现仍保留；
随机数驱动使用新版 `HW_RANDOM_QCOM`。

迁移期间修正了 GPIO 分类、CAMCC 父电源域、初始 PLL 偏置、扬声器格式约束、
USB 共享电源恢复和 DP 探测清理。补丁顺序以来源记录中的 `target_patches` 为准。
这些修正不代表内屏偶发闪烁的根因已经消除。

## 构建与回退

使用普通构建配置即可，无需额外的 7.3 实验配置：

```sh
devbox run kernel -- --configure-only
devbox run kernel-packages
```

`build.json` 的目标源码目录应使用新的 `sources/linux-liuqin-7.3`，不要把旧的 6.17
自定义源码目录误当作新基线。默认包版本为 `0.3.3`，原有 ROM、USB 名称和 rootfs 定制可继续使用。
配置快照用于保留设备能力；构建时继续叠加板级、发行版和自定义片段。

需要构建旧版目标时，在另一份配置中设置：

```json
{
  "kernel_source": "sources/linux-sm8450-liuqin",
  "kernel_source_lock": "build/kernel/source-6.17.json",
  "kernel_localversion": "-liuqin-fedora"
}
```

其余字段沿用普通配置。目标来源覆盖不会改变安装环境运行内核的来源。
每次更新须使用配套的 Image、模块与 boot，不混用 6.17 和 7.3 模块；
设备更新继续保留完整旧引导和旧模块，系统内自动写引导仍默认停用。

## 验证范围与待办

7.3 基线（加入 Caps Lock 修复前）在一台天马屏、8GB / 256GB、HW16.9.0 设备上验证：

- 临时启动、A 槽完整回读、普通重启及拔线冷启动。
- 首次显示、触屏、磁吸键盘、低到中等亮度、Wi-Fi、扬声器播放、自动旋转和后摄预览。
- 指纹录入、已录手指解锁、未录手指拒绝。
- 短时 deep 睡眠、键盘唤醒、唤醒后的指纹解锁和 USB 2.0 NCM 实际通信。
  基线验收中的睡眠失败计数为 0，USB 初始化超时与时钟配对告警、空闲端口的 DP 上电超时未再出现。

Caps Lock 补丁参考 NixOS 项目的原厂 LED 命令。首版临时测试覆盖亮灭、大小写、重接及唤醒同步；
收尾版等待键盘有效回复后再发送，已复测亮灭与唤醒，未再新增 LED 发送超时。
该补丁固定引导后的重启验证待完成。本轮还记录过睡眠进入被唤醒信号打断和显示恢复事件，
因此指示灯通过不代表睡眠与显示问题已解决。

仍需保留以下限制：

- 已抓取 7.3 普通熄屏亮屏后持续闪烁的故障与恢复对照：恢复 10 秒启动等待后仍可复现，
  故障时 PWM 稳定、没有面板告警，关闭再开启显示输出后恢复。**尚未定位或确认修复**，
  也未证明与开机条纹、黑屏同源。命令扫描行调度的新一轮短测与冷启动通过，见[显示文档](DISPLAY.md#命令扫描行调度)。
- 原有偶发开机显示异常、待机提前唤醒和电量刷新问题未宣告解决；短时 deep 通过不代表长时待机耗电可靠。
- USB SuperSpeed、外接 DP、蓝牙实际连接、触控笔、麦克风、其他面板及容量组合仍有本轮验证缺口。
  当前静态音频拓扑未导出录音前端是已有构建缺口，不记为 7.3 回归。
- 睡眠前仍可记录 `HS-PHY not in L2` 提示；本轮 deep 和 USB 2.0 恢复通过，长期表现继续观察。

离线检查包括完整项目回归、补丁重放、配置一致性、启动镜像与模块契约，
以及 GPIO/电源域、首帧背光、面板告警、电池换算、PLL 引用、音频和 USB/DP 生命周期的源码执行测试。
测试保留旧版缺陷反例；自动恢复发生时单独记录，不能将其合并成“首次显示正常”。
