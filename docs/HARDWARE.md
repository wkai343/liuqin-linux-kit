# 硬件支持与已知限制

[项目首页](../README.md) ｜ [构建指南](BUILD.md)

适配对象为 Xiaomi Pad 6 Pro（liuqin，SM8475）。以下保留已确认的功能和限制；具体操作见各专题，内核来源及补丁见 [source.json](../build/kernel/source.json)。

## 系统、显示与输入

| 功能 | 支持状态与限制 |
| --- | --- |
| 系统安装与引导 | Android 与 ext4/Btrfs Linux 的安装、启动、正常重启及默认系统切换已验证；支持一个 Android 与多个 Linux |
| 内置存储 | UFS，支持 ext4/Btrfs；分区按实际容量规划，不套用其他容量的布局 |
| GPU / 桌面合成 | Adreno 730、Freedreno/Mesa 硬件加速；部分应用仍需渲染兼容设置 |
| GPU 监测 | KSystemStats 已支持使用率、频率、概览和历史页；不提供独立显存、GPU 温度或功耗 |
| 内置显示 | Novatek NT36532、双 DSI、DSC，2880 × 1800；默认 90/120/144 Hz，首选 120 Hz；低频档位仍有闪烁或面板告警，见[显示](DISPLAY.md) |
| 亮度与启动画面 | 手动亮度、CABC、Plymouth 动画和调光可用；启动接管仍可能短暂黑屏 |
| 触控 | 按 CSOT/TM 面板选择 Novatek 固件；点击、滑动及普通熄屏恢复可用，异常恢复和边界见[显示](DISPLAY.md#显示与触摸恢复时序) |
| 磁吸键盘 | Nanosic WN8030 按键、音量键、重新吸附、Caps Lock 同步及合盖/背折输入屏蔽已接入；触控板手势覆盖仍不完整 |
| 自动旋转 | 拆下键盘进入平板模式并恢复旋转，接上停止旋转；登录界面默认横屏 |
| 指纹锁屏 | fprintd 按账号隔离，支持每账号最多五枚；两枚录入、分别解锁和未录手指拒绝已验证。五枚录满、多账号切换及休眠恢复尚未完成专项测试，见[指纹](FINGERPRINT.md) |
| 手写笔 | 已有输入接口，坐标、压感、按键与唤醒恢复仍缺少完整测试 |
| 中文与输入法 | 中文语言、字体、Firefox 中文、Fcitx5 和 Plasma 屏幕键盘；旧应用的屏幕键盘兼容性按应用判断 |
| 内存 | 8GB 配置可管理约 6.8 GiB，启用 zram；默认设备树不含 MTE 512 MiB 预留，其余固件保留区域不回收 |

### 磁吸键盘的合盖与背折

| 状态 | 行为 |
| --- | --- |
| 展开在前方 | 正常输入，退出平板模式，沿用用户保存的显示方向 |
| 拆下 | 按 MCU 连接报告进入平板模式，恢复自动旋转 |
| 背折 | GPIO23 有效时进入平板模式，屏蔽磁吸键盘的按键、多媒体键、鼠标和触控板输入 |
| 合盖 | GPIO10 上报 SW_LID；Plasma 默认锁屏并熄屏，屏蔽磁吸键盘输入；开盖亮屏并保持锁定 |

输入屏蔽前发送释放报告，展开或开盖后恢复。普通 USB / 蓝牙键鼠不属于此路径；连接判断使用 MCU 状态，不把键盘闲置当作拆下。

Plasma 的 AC、Battery、LowBattery 默认选择关闭屏幕并先锁定；logind 不另行执行合盖睡眠。用户电源设置优先，外接显示器时沿用桌面例外。
NanoSic I2C 目录的 `folio_posture`、`tablet_mode`、`keyboard_status` 及 SW_LID 事件用于排查。实现见[键盘与姿态补丁](../build/kernel/patches/linux-7.3/0012-nanosic-folio-posture.patch)。

## 无线、USB 与音视频

| 功能 | 支持状态与限制 |
| --- | --- |
| Wi-Fi | QCA6490 / WCN6855，搜索、5 GHz 连接和日常联网可用 |
| 蓝牙 | QCA6490 / hci_qca / BlueZ；已接入上游适配，当前配方的配对及睡眠恢复覆盖仍不完整 |
| USB OTG | 预接 U 盘启动、角色切换、exFAT 挂载和目录读取已验证；外接磁盘保持原有可写标志 |
| USB 3.x | 已协商到 5 Gbit/s；同一 U 盘的插头方向存在 480 Mbit/s / 5 Gbit/s 差异，原因未确定 |
| USB-C 外接显示 | 已接入 DisplayPort Alt Mode / FSA4480；上游支持外屏与拔插恢复，当前配方的外屏、DP 音频和高刷测试不完整 |
| 四扬声器 | CS35L41 / AudioReach，立体声播放和音量控制可用，使用设备校准；音质仍可改进 |
| 内置麦克风 | 上游支持单声道 48 kHz 录音；当前 Fedora 静态拓扑仍缺录音前端，其余麦克风与降噪未接入 |
| H.264 硬解 | 已接入 Iris2 / V4L2 驱动；上游已有硬解支持，浏览器接入不由内核驱动单独保证 |
| 后摄 | S5KJN1、CAMSS/libcamera、CPU 软件 ISP；Kamoso 预览/拍照和 QRCA 灰度扫码可用，见[相机](CAMERA.md) |
| 前摄 | 尚未启用 |
| 传感器 | 自动旋转可用；环境光真实测量及其他传感器功能覆盖仍不完整 |

桌面仅封存内部 UFS，外接磁盘保持原权限；安装、充电和失败回退封存全部 SCSI 设备。桌面不创建诊断 USB 网络，Rec 使用 ADB。

## 电源、时间与睡眠

| 功能 | 支持状态与限制 |
| --- | --- |
| 电源键 / 音量键 | 电源菜单、亮屏和音量调整可用；短按电源的具体动作由桌面配置决定 |
| 电池显示 | UPower / PowerDevil 可显示电量和充电状态；容量单位已修正，电量计刷新延迟仍需处理 |
| USB 充电 | 保持电脑 USB 连接的普通重启充电已验证；不使用 PD 复位或自动恢复服务，见[充电](FASTCHARGE.md) |
| 快充 | 电芯认证及 MiPPS/PPS 适配已接入；基础充电可用，快充适配器的功率范围仍需分别测量 |
| RTC | Linux 私有偏移校准、联网保存、离线重启和关机后恢复时间已验证；长期漂移、拔线关机及掉电重置仍需扩大测试，见[RTC](RTC.md) |
| 睡眠 | 默认 s2idle；600 秒待机及 RTC、键盘、电源键唤醒已验证。deep 存在提前唤醒与串口/蓝牙恢复问题，不作为默认策略 |

### 睡眠策略

默认 [30-liuqin-suspend.conf](../device/board-overlay/usr/lib/systemd/sleep.conf.d/30-liuqin-suspend.conf) 使用 `SuspendState=freeze`。`/sys/power/mem_sleep` 显示的默认项不能代替实际睡眠路径，应检查日志中的 `PM: suspend entry (s2idle)`。

ADSP 电池更新通知可能唤醒 PSCI deep；不屏蔽正常电池通知。deep 再入睡原型没有加入默认构建，长期待机功耗及睡眠中的键盘姿态变化仍需完善。

## 待改进

- 显示：低频档位、CSOT、长期唤醒、无缝刷新率及无黑屏连续接管；双路 DSI 时钟门控保持关闭。
- 电源：电量刷新、可靠的长期功耗测量、deep 提前唤醒与恢复；不采用运行中重启 ADSP 或 warm 重启作为充电修复。
- 输入与媒体：触控板/手写笔完整交互、麦克风录音前端、前摄及相机调校。
- 启动维护：系统内自动内核写入默认停用；固定 Rec 按固件检查，不承诺任意 ROM 自动适配。
- SMEM DDR：492 字节布局保留诊断与兜底，未定义字段不作推测解析。

离线检查入口和覆盖范围见[测试说明](../tests/README.md)。显示、指纹、相机、充电与 RTC 的实现和诊断命令分别在对应专题维护。
