# 小米平板 6 Pro 硬件说明

[项目首页](../README.md) ｜ [原设备适配来源](https://github.com/yzddmr6/xiaomipad-6pro-mainline)

## 本项目已验证范围

以下结果来自一台 256GB / HW16.9.0 设备的 Fedora 44 / KDE Plasma 已安装系统。
修复包已完成 Linux GUI 单根 Btrfs 安装、桌面启动及正常重启。
Windows 主机 GUI 安装也已由用户确认成功；具体 Windows 版本、文件系统及重启结果尚未记录。
硬件功能来自已安装系统的分项测试，未按 ext4、Btrfs 分别重复全套验收。
128GB / 512GB 的容量规划通过离线检查，未逐一实测。

| 功能 | 已验证与限制 |
| --- | --- |
| 单根启动、桌面和重启 | userdata ext4/Btrfs、A 槽；桌面启动与正常重启已验证 |
| 中文与输入 | 中文语言、字体、Firefox 中文、Plasma 键盘、Fcitx5；旧应用的屏幕键盘兼容性需分别判断 |
| Wi-Fi | 搜索网络、连接与日常联网 |
| HiFi 扬声器 | 可播放；内置声卡隐藏不可用的 Pro Audio 配置 |
| 自动旋转与磁吸键盘 | 取下进入平板模式，接上停止旋转；键盘与触控板可用 |
| 登录界面 | 接键盘默认横屏，平板模式可旋转；开机仍用密码 |
| 开机显示 | Fedora Plymouth 动画、调光和睡眠唤醒可用；仍有偶发条纹、闪烁及黑屏，自动恢复已实测生效，根因未解决，见[显示说明](DISPLAY.md) |
| 指纹锁屏 | KDE 设置录入、已录手指通过、异指拒绝和正常重启后锁屏验证；见[指纹](FINGERPRINT.md) |
| USB U 盘 | 内核枚举与 exFAT 挂载可用；依赖 UDisks 等桌面组件 |
| 电池显示 | UPower 与 PowerDevil 可显示电量；容量单位修正已真机核对，移除固定的假功率值。电量计刷新延迟仍待核实 |
| 深度睡眠与待机 | 临时诊断内核的 deep、RTC 与键盘唤醒通过短测，长测仍提前唤醒；默认构建尚未合入键盘唤醒试验，亦无可靠待机功耗结论，见[待办](DEVELOPMENT-STATUS.md) |
| GPU 监测 | Adreno 使用率与频率、系统监视器概览及历史页可用 |
| 后摄 | Kamoso 预览/拍照、QRCA 灰度实时扫码；前摄未启用，见[相机](CAMERA.md) |
| 内存 | MTE 512 MiB 回收后约 6.8 GiB；zram 已启用；MPSS 回收试验失败，保留原预留 |

MTE 预留已通过早期全 1 / 全 0 读写测试；其余 116 MiB 区域由固件排除在 RAM 映射之外，
保留原节点。可选构建项见 [构建指南](BUILD.md#可选回收-mte-预留)。
蓝牙、外屏、麦克风、硬件视频解码、挂起恢复、快充适配器等未随 Fedora 完成完整复测。

## 板级器件与上游能力参考

以下器件信息和扩展能力主要保留 yzddmr6 原项目的 Ubuntu/GNOME 记录。
范围明确注明 Fedora 的行属于本项目结果；其他“可用/已验证”不代表 Fedora 已复测。
保留这些资料用于设备开发，不沿用原作者的版本号或发布承诺。

✅ 可用 · 🟡 部分支持 · ❌ 不支持 · 🧪 未验证

### 平台、显示与输入

| 功能 | 器件 / 实现 | 状态 | 范围与限制 |
|---|---|---|---|
| SoC / CPU | Qualcomm Snapdragon 8+ Gen 1（SM8475），ARM64 | ✅ 可用 | 主线内核启动与 Ubuntu 桌面运行；不代表全部节能状态已验证 |
| GPU / 桌面合成 | Adreno 730 / Freedreno / Mesa | ✅ 可用 | 桌面硬件加速；部分应用仍需渲染兼容设置 |
| GPU 使用率 / 频率监测 | KSystemStats Adreno 平台适配 | ✅ 可用 | Fedora 概览与历史页已真机验证；读取内核使用率与 devfreq 频率，不提供独立显存、GPU 温度或功耗 |
| 内置存储 | UFS / ext4 | ✅ 可用 | 256GB 单根方案已验证；128GB / 512GB 按实际容量规划并通过离线检查，尚未逐一真机验收 |
| 内置显示 | Novatek NT36532 / 双 DSI / DSC | ✅ 可用 | 2880 x 1800，120 Hz；其他刷新率未逐项验证 |
| 手动亮度 | Kinetic KTZ8866 背光控制 | ✅ 可用 | 背光与手动亮度调节 |
| 触控 | Novatek NT36532 / SPI（CSOT 或 TM 面板） | ✅ 可用 | 驱动按面板模块选择固件；点击、滑动与触控手势 |
| 磁吸键盘 | Nanosic WN8030 | ✅ 可用 | 普通按键、音量键、触摸板与重新吸附输入；挂起后恢复未完整覆盖 |
| 指纹 | FPC1264 / libfprint TOD / fprintd | 🟡 部分支持 | 上游 Ubuntu 已验证原生录入、同指通过/异指拒绝、锁屏及重启后登录，限 UID 1000、一枚指纹；本分支 Fedora 已集成专用 RPM，KDE 设置录入、同指通过/异指拒绝、正式内核固定及普通重启后的锁屏已验证；开机登录保留现有密码流程，见[指纹说明](FINGERPRINT.md) |
| 手写笔 | NVTCapacitivePen 输入接口 | 🧪 未验证 | 坐标、压感、按键及唤醒后的笔输入未实测 |
| 霍尔开关 | GPIO / SW_LID | 🟡 部分支持 | 合盖开关保留；GPIO23 不能表示键盘连接，目标内核已移除其平板模式映射；保护套唤醒策略未完整验收 |
| 仅平板模式自动旋转 | NanoSic 连接状态 / 独立 SW_TABLET_MODE / 官方 KWin | ✅ 可用 | 正式内核、官方 KWin、正常重启后接上停止旋转与取下恢复旋转均已真机验证；登录管理器默认横屏、平板模式下自动旋转 |

### 无线与 USB

| 功能 | 器件 / 实现 | 状态 | 范围与限制 |
|---|---|---|---|
| Wi-Fi 2.4 GHz | Qualcomm QCA6490 / ath11k | ✅ 可用 | 无线连接与日常联网 |
| Wi-Fi 5 GHz | QCA6490，按 WCN6855 系列适配 | ✅ 可用 | 5 GHz 连接已验证；不承诺特定峰值速率 |
| Wi-Fi 热点 / AP | NetworkManager / ath11k | 🧪 未验证 | 当前已确认的联网场景为客户端模式 |
| 蓝牙 | QCA6490 / hci_qca / BlueZ | ✅ 可用 | 日常蓝牙功能可用 |
| USB 2.0 设备模式 | Synopsys DWC3 / NXP eUSB2 repeater | ✅ 可用 | USB NCM 网络与数据传输；当前为 High-Speed 设备模式 |
| USB 充电器切换后重连 | USB-C / USB gadget | 🟡 部分支持 | 上游适配采用 UCSI typec 自动协商，可靠性预期改善；专项复测待做 |
| USB 3.x SuperSpeed | USB 控制器 / PHY | 🧪 未验证 | 上游 SM8475 PHY 表与控制器已就绪；SuperSpeed 外设枚举未实测 |
| USB OTG / 主机模式 | USB-C 数据角色切换 | ✅ 可用 | 上游 UCSI 自动角色协商；上游有线鼠标可用；本项目 Fedora 已验证 exFAT U 盘挂载，扩展坞未复测 |
| USB-C 外接显示 | DisplayPort Alt Mode / FSA4480 | ✅ 可用 | 已测显示器/转接器组合下，真实外屏、拔出恢复内屏、接回电脑恢复 USB 已验证；其他扩展坞、DP 音频和高刷未逐项验收 |

| 功能 | 器件 / 实现 | 状态 | 范围与限制 |
|---|---|---|---|
| 四扬声器 | 4 × Cirrus Logic CS35L41 / AudioReach | ✅ 可用 | 立体声播放与音量控制，读取本机校准；音质仍在调校 |
| 内置麦克风 | WCD938x AMIC1 经 SoundWire → LPASS TX macro → ADSP codec DMA | ✅ 可用 | 上游提供单声道 48 kHz 录音，已通过真机验证；其余三颗麦克风与降噪尚未接入 |

| 浏览器视频硬解 | 浏览器 / V4L2 接入 | 🧪 未验证 | 浏览器能播放视频不等于使用硬件解码 |
| 硬件视频编码 | Qualcomm 视频引擎 | 🧪 未验证 | 尚未验证硬件编码工作流 |
| 后置摄像头 | S5KJN1 / Qualcomm CAMSS / libcamera 软件图像处理 | 🟡 部分支持 | 上游 Ubuntu 已测预览、拍照、录像；本分支 Fedora 已测普通用户 1280×720 采集约 30 fps，Kamoso 预览与拍照可用、默认高分辨率预览偏慢；录像未测，无自动对焦，见[相机](CAMERA.md) |
| 前置摄像头 | 相机传感器 / CAMSS | ❌ 不支持 | 尚未启用或验证 |
| 加速度计 / 自动旋转 | SLPI / SSC / iio-sensor-proxy | ✅ 可用 | 首次启动、登录界面、桌面横竖旋转与磁吸键盘横屏 |
| 陀螺仪 / 磁力计 | SSC 传感器链路 | 🧪 未验证 | 未确认应用可用的测量链路，不随自动旋转标为可用 |
| 环境光传感器 | SSC 光感路径 | 🧪 未验证 | 尚未完成真实光照测量验收 |
| 自动亮度 | 桌面亮度策略 | ❌ 不支持 | 尚未接通自动亮度控制 |
