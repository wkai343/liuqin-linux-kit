当前 7.3 的复测范围见 [内核验收](KERNEL-7.3.md)，不能把旧版结果当作新版完整镜像的安装验收。
修复包已完成 Linux GUI 单根 Btrfs 安装、桌面启动及正常重启。
Windows 主机 GUI 安装也已由用户确认成功；具体 Windows 版本、文件系统及重启结果尚未记录。
硬件功能来自已安装系统的分项测试，未按 ext4、Btrfs 分别重复全套验收。
128GB / 512GB 的容量规划通过离线检查，未逐一实测。

### 磁吸键盘的合盖与背折

默认 7.3 配方新增 `0012-nanosic-folio-posture.patch`。2026-10-21 在一台天马屏、
8GB / 256GB、HW16.9.0 设备上完成 Fastboot **临时启动真机测试**，系统为 Fedora 44 / KDE 6.7.5。
测试源码为 `b98f45849b3d52b125156f35a4fdbf91df778a56`，
源码树为 `a24bdfeeea734fab2c103f33b8e753de0e2a5e97`，内核为 `7.3.0-liuqin-folio-test-gb98f45849b3d`。
临时启动镜像 SHA256 为 `00138ad20bc0b9d85081a2bf21196e387df6d9b698bd478588091aaf78d0141d`。
原 boot_a 完整校验值保持不变，未固定引导；旧 6.17 安装环境不包含背折补丁。

| 状态 | 预期行为 |
| --- | --- |
| 键盘展开在前方 | 正常输入，退出平板模式，沿用用户保存的显示方向 |
| 拆下键盘 | 按 MCU 连接报告进入平板模式，恢复自动旋转 |
| 键盘背折 | GPIO23 有效时进入平板模式，屏蔽磁吸键盘的按键、多媒体键、鼠标和触控板输入 |
| 合盖 | GPIO10 上报 SW_LID；Plasma 默认锁屏并熄屏，驱动屏蔽磁吸键盘输入；开盖由 KWin 恢复亮屏，保持锁定 |

输入屏蔽前会发送释放报告，清除按住的修饰键、鼠标按钮和触点；展开或开盖后恢复输入。
GPIO10 仅由 gpio-keys 申请，NanoSic 通过输入事件观察它；GPIO23 的 GPIO 和引脚状态独立交给 NanoSic。
连接判断仍使用 MCU 状态，不把键盘闲置当成拆下，也不增加周期查询。
触控板恢复为内部设备分类；普通 USB / 蓝牙键鼠不属于这条输入屏蔽路径。

Plasma 的 AC、Battery、LowBattery 默认配置均选择“关闭屏幕”并启用关闭前锁定。
logind 不再自行执行合盖睡眠；Fedora 的 Plasma Login 会话也启动 PowerDevil。
用户已有的电源设置优先于这些默认值；升级后若仍然合盖睡眠，请在系统设置的电源管理中检查合盖动作。
保留外接显示器时的桌面默认例外；Ubuntu SDDM 登录界面的合盖处理不在本轮实现范围。

本轮用户操作与事件记录共同确认：

- 登录界面、桌面的合盖熄屏与开盖恢复正常，用户确认锁屏、显示和触控正常。
  合盖记录为 `lid_closed=1 input_muted=1`，背光电源由 0 变为 4；开盖后恢复为 0。
- 背折时 `folded=1 input_muted=1 tablet_mode=1`，用户确认自动旋转及键盘停止响应。
  约 17 秒背折窗口内，按键计数没有增加；正常展开时的三次 Shift 对照被记录。
- 按住 Shift 背折时，已按下键数由 1 变为 0，并产生释放事件、停止重复输入；
  展开后的新按键正常上报，横屏恢复，未出现卡键。
- 开盖后的触控状态为 `reset=a3`，面板检测未新增故障事件；临时监测和睡眠抑制已停止。

本轮没有重复拆装验收，也没有真机覆盖触控板点击/滚动/手势或按住触点翻折。
固定引导后的重启/冷启动、连续长测、睡眠期间拆装/翻折、Caps Lock 重接同步及其他硬件仍需验证。
三触点释放由离线模拟测试覆盖，不能据此标为触控板真机通过。
驱动新增只读 `folio_posture`（folded / lid_closed / input_muted / tablet_mode）和
`tablet_mode` 属性，位于 NanoSic I2C 设备目录；结合原有 `keyboard_status` 与 SW_LID 事件定位问题。
本次配置不代表深度睡眠和长时间待机已经修复。
